# Decision Gate

Use this before architecture, dependency, compliance, security, privacy, licensing, folder-structure, API-contract, product-direction, or design-direction decisions.

Required output:
- Decision needed
- Options
- Tradeoffs
- Recommended option
- Questions for the user

Do not implement until the user approves the direction.
